# Array + String Interview Questions

## Arrays

### Basic
1. Find the largest element in an array.
2. Find the smallest element in an array.
3. Find the second largest element.
4. Reverse an array in-place.
5. Check if an array is sorted.
6. Move all zeroes to the end.
7. Remove duplicates from a sorted array.
8. Count positive, negative and zero values.

### Intermediate
9. Find the missing number from 1 to n.
10. Find the duplicate number.
11. Find the frequency of each element.
12. Find the maximum subarray sum (Kadane's Algorithm).
13. Find the pair with a given sum.
14. Find the intersection of two arrays.
15. Merge two sorted arrays.
16. Find the majority element.
17. Rotate an array by k positions.
18. Find the best time to buy and sell stock.
19. Find all leaders in an array.
20. Find the maximum product subarray.

### Interview / Pattern Practice
21. Two Sum using HashMap.
22. Three Sum.
23. Sort an array containing only 0, 1 and 2.
24. Find the longest consecutive sequence.
25. Find the subarray with a given sum.
26. Find the equilibrium/pivot index.
27. Product of array except self.
28. Jump Game.
29. Container With Most Water.
30. Merge overlapping intervals.

## Strings

### Basic
1. Reverse a string.
2. Check whether a string is a palindrome.
3. Count vowels and consonants.
4. Count the frequency of each character.
5. Remove duplicate characters.
6. Find the first non-repeating character.
7. Find the first repeating character.
8. Check whether two strings are equal ignoring case.
9. Count words in a sentence.
10. Reverse words in a sentence.

### Intermediate
11. Check whether two strings are anagrams.
12. Check whether one string is a rotation of another.
13. Find the longest common prefix.
14. Find the longest substring without repeating characters.
15. Find the maximum number of vowels in a substring of size k.
16. Find all anagram occurrences of a pattern.
17. Implement string compression.
18. Find the most frequent character.
19. Check whether a string contains only unique characters.
20. Convert Roman numerals to an integer.

### Interview / Pattern Practice
21. Longest Palindromic Substring.
22. Valid Parentheses.
23. Group Anagrams.
24. Minimum Window Substring.
25. Longest Repeating Character Replacement.
26. String to Integer (atoi).
27. Compare Version Numbers.
28. Isomorphic Strings.
29. Valid Palindrome II.
30. Implement strStr()/indexOf().

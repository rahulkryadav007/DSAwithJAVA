# Arrays — Basic Practice

I am keeping these programs small so I can understand the logic and explain it during practice or while teaching.

## Programs

| Program | What it does |
|---|---|
| [FindLargest.java](FindLargest.java) | Finds the largest value in an array |
| [FindSmallest.java](FindSmallest.java) | Finds the smallest value in an array |
| [LinearSearch.java](LinearSearch.java) | Searches for a value one by one |
| [SumOfArray.java](SumOfArray.java) | Adds all array elements |
| [CountEvenOdd.java](CountEvenOdd.java) | Counts even and odd numbers |
| [CountPositiveNegativeZero.java](CountPositiveNegativeZero.java) | Counts positive, negative and zero values |
| [CopyArray.java](CopyArray.java) | Copies elements into another array |
| [CountOccurrences.java](CountOccurrences.java) | Counts how many times a target appears |
| [ReverseArray.java](ReverseArray.java) | Reverses an array |

## Practice tip

Run each file separately. First dry-run the loop on paper, then change the sample array and test edge cases such as one element or repeated values.

Most of these are single-pass problems with `O(n)` time. Check each file for its exact complexity.

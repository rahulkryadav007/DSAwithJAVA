# Arrays & Strings — Practice Roadmap

This roadmap is for learning and interview practice. Each problem should have its own runnable Java file (with `main()`), plus a separate LeetCode/GFG-style `class Solution` version when the platform requires it.

## Standard format for every problem

1. Problem statement + platform link/number (where applicable)
2. Example input/output
3. Approach in simple English + Hinglish
4. Dry run / trace table
5. Complete runnable Java program (`main()`)
6. Platform submission version (`class Solution`, if needed)
7. Time and space complexity
8. Hinglish comments and common mistakes

## Folder convention

```text
01-Arrays/
  Basic/
  Intermediate/
  Advanced/       # optional later
02-Strings/
  Basic/
  Intermediate/
  Advanced/       # optional later
```

Keep each question in a separate, clearly named `.java` file. Do not combine unrelated questions into one Java file. Prioritize Easy and Intermediate before moving to Advanced.

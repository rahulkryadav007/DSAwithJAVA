# 04 - Linked List

My Linked List learning and practice journey in Java.

## Learning Flow

1. Node, data, next and head
2. Traversal
3. Search
4. Insert at beginning
5. Insert at end
6. Insert at a position
7. Delete from beginning
8. Delete from end
9. Delete by value
10. Reverse Linked List
11. Find Middle
12. Nth Node from End
13. Detect Cycle
14. Merge Two Sorted Lists
15. Add Two Numbers

## Practice Rule

For every problem:
- Understand the concept
- Draw the linked list
- Dry run with a small example
- Write Java code
- Note time and space complexity
- Explain the solution in simple words

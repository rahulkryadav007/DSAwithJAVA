## Key learning

A running sum at index `i` is the sum of all array elements from index `0` through `i`.

For an in-place solution:
```java
nums[i] = nums[i] + nums[i - 1];
```

The previous index already stores the running total, so we can update the current index in one pass.

## Complexity

- **Time:** O(n)
- **Auxiliary space:** O(1), because the input array is updated in place.
